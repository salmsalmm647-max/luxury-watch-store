متجر الساعات الفاخرة — ملفات جاهزة للنشر على GitHub Pages

مهم قبل التشغيل:
1) المتجر يستخدم نفس مشروع Firebase المستخدم في متجر السعادة:
   projectId: vip-store-d75d1
2) البيانات محفوظة في مجموعات منفصلة حتى لا تختلط ببيانات متجر السعادة:
   watch_products
   watch_categories
   watch_orders
   watch_pageViews
   watch_settings
3) افتح firebase.js وابحث عن:
   ضع_API_KEY_العام_هنا
   واستبدله بقيمة apiKey الموجودة في ملف firebase.js الحالي لمتجر السعادة.
   لا تضع كلمة مرور حسابك أو مفاتيح خدمة Admin SDK هنا.
4) في Firebase Console > Firestore Database > Rules:
   انسخ محتوى firestore.rules وانشره. هذه القواعد تسمح للزوار بإنشاء طلبات وزيارات، وتقيّد إدارة البيانات بحساب المدير UID الموجود في الملف.
   إذا كان لديك قواعد سابقة لمتجر السعادة، لا تستبدلها عشوائياً؛ أضف قواعد watch_* إليها مع الإبقاء على قواعد المتجر الآخر.
5) تأكد أن حساب المدير موجود في Firebase Authentication بنفس UID:
   JZBRq09omwXLHUt3EiiAIlQL6Xi2
   الدخول يكون ببريد المدير وكلمة مروره اللذين أنشأتهما في Firebase، ولا تضعهما داخل الملفات.
6) أنشئ مستودع GitHub أو افتح المستودع المطلوب، وارفع جميع الملفات في جذر المستودع:
   index.html, style.css, store.js, firebase.js,
   admin.html, admin.css, admin.js, firestore.rules
7) من Settings > Pages اختر Deploy from a branch ثم الفرع main والمجلد /(root).
8) رابط المتجر سيكون رابط GitHub Pages للمستودع، ولوحة التحكم على نفس الرابط مع /admin.html.

طريقة إضافة المنتجات:
- افتح /admin.html وسجل الدخول.
- من المنتجات اكتب الاسم والسعر والقسم والوصف ورابط صورة مباشر يبدأ بـ https:// ثم احفظ.
- من الأقسام أضف اسم القسم ورابط صورته.
- من إعدادات المتجر عدّل الاسم والبريد والهاتف والشعار والخلفية والنصوص.

هذا الإصدار يقبل روابط صور مباشرة. رفع الملفات من الهاتف إلى Firebase Storage لم يفعّل بعد؛ لا تضع رابط صفحة ويب عادية بدلاً من رابط الصورة المباشر.
